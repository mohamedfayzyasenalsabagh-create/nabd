## التشغيل لأول مرة

1. **قواعد الحماية:** Firebase Console ← Firestore ← Rules ← الصق محتوى `firestore.rules` ← Publish.
2. **رابط الموقع:** GitHub ← المستودع ← Settings ← Pages ← Branch: `main` ← Save.
3. **حساب المالك:** افتح `…/nabd/#/owner`، وأنشئ حسابك (مرة واحدة فقط).
4. **من لوحة المالك ← الإعدادات:** أدخل أرقام سيريتل كاش وMTN كاش وواتساب التواصل، وعدّل أسعار الباقات.

## ما يعمل الآن دون أي تكلفة

كل ما سبق، إضافة إلى: صفحة حجز عامة لكل عيادة `#/b/رمز-العيادة`، التحقق من الوصفة `#/v/الرمز`، الإملاء الصوتي في المتصفح (Chrome)، الوضع الداكن، شاشة الانتظار، التقارير، سجل التعديلات، النسخة الاحتياطية اليدوية، والعمل دون إنترنت.

## ما يحتاج خطة Firebase Blaze (مدفوعة حسب الاستخدام)

موجود جاهزاً في مجلد `functions`، ويُفعَّل عند الترقية:

- **تذكير واتساب تلقائي** بمواعيد الغد الساعة 6 مساءً. يحتاج حساب WhatsApp Business API من Meta (`WHATSAPP_TOKEN` و `WHATSAPP_PHONE_ID`).
- **نسخة احتياطية يومية** لكامل قاعدة البيانات في Cloud Storage (`BACKUP_BUCKET`).
- **النشر التلقائي** لقواعد الحماية والخدمات عبر GitHub عند إضافة السر `FIREBASE_SERVICE_ACCOUNT`.

## Google Play

كل بناء يُخرج ملفين في صفحة Releases:
- `nabd.apk` للتثبيت المباشر.
- `nabd-play.aab` للرفع على Google Play (يحتاج حساب مطوّر برسوم 25$ لمرة واحدة، وسياسة خصوصية منشورة).

**قبل النشر على Google Play:** مفتاح التوقيع `android/nabd.keystore` موجود حالياً في المستودع العام. انقله إلى أسرار GitHub (Secrets) ثم احذفه من المستودع، وفعّل «Play App Signing».
